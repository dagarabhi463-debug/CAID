Dataset: `data/independent_v2/` generated by `data/generate_independent_datasets_v2.py` (seed 20260220). Existing `data/independent/` v1.9 splits were not modified. Leakage audit: `data/independent_v2/leakage_audit.json` → passed.

Artifacts fitted on `train.csv` label=`normal` only; thresholds calibrated on `calibration.csv` label=`normal` only; `validation.csv` used for sanity only; `holdout.csv` used for report only. No holdout tuning.

Prediction label: `suspicious` + `high_risk` = positive. Alert label: `risk_level` High/Critical. Scores are calibrated anomaly scores, not probabilities.

## Scenario highlights

- **Unseen users** (`holdout_only` cohort): v2_complete ROC-AUC 0.9433 / PR-AUC 0.8886 vs v1_9 0.9018 / 0.8672; recall is lower (0.3898 vs 0.5339) under fixed thresholds.
- **Previously normal → suspicious**: v2_complete ROC-AUC 0.8445 / PR-AUC 0.8737 vs v1_9 0.7863 / 0.8529; F1 lower (0.5657 vs 0.6242) because fixed combined-score weights/thresholds were not tuned on holdout.
- **Previously suspicious → normal**: v2_complete ROC-AUC 0.9891 / PR-AUC 0.9018 vs v1_9 0.9822 / 0.8360; FPR remains low (0.0029).
- **Common-IP positives**: all variants have precision 1.0 on this subset; v2_complete recall 0.4479 vs v1_9 0.4858.

## Interpretation

- Session and sequence channels improve ranking quality: v2_complete has the highest ROC-AUC (0.9177) and PR-AUC (0.8224).
- Sequence-only matches/slightly exceeds v1_9 F1 (0.6401 vs 0.6392) while preserving precision and low FPR.
- The complete fixed-weight v2 profile trades recall for specificity/ranking; this is an explicit operating-point result, not evidence of real-world accuracy.
- v2_ml_rules_behavioral is lower than v1_9 on this independent set, showing dataset/version sensitivity; comparisons are synthetic-only.
